# go2rtc 小米摄像头码流配置说明设计

## 目标

把 `docs/poc-runbook.md` 第 3 节中“配置两台摄像头”的一句话展开为可直接执行且可验证的操作步骤。

## 范围

保留现有的 go2rtc 启动、SSH 隧道和小米账号登录说明，不重复描述以下步骤：

- 建立 SSH 隧道并打开 Web UI。
- 进入 `Add → Xiaomi` 登录小米账号。
- 处理短信、邮件或图片验证码。

新增内容从账号已登录、摄像头列表已显示开始：

1. 根据米家中的设备名称和实时画面分别识别两台摄像头，不能只依赖设备列表顺序。
2. 将两路流固定命名为 `xiaobai` 和 `xiaobai_25k`。
3. 优先为每路源地址设置 `subtype=sd`，保存后逐路预览。
4. 如果 `sd` 不可用，按 `auto`、`1`、`2` 的顺序逐项测试；每次只改一个值，并记录最终可用值。
5. 用 `/api/streams` 确认两个固定名称存在，用对应 RTSP 地址确认两路均能读取。
6. 给出脱敏后的 YAML 结构示例，说明 Web UI 保存的 `xiaomi://` 地址不得复制到报告或提交到 Git。

## 成功标准

- 用户可以从已登录的 Xiaomi 设备列表完成两路流的创建、命名、质量选择和验证。
- 操作步骤不要求用户手工拼接 Xiaomi URL。
- 不泄露账号令牌、DID、局域网 IP 或完整摄像头源地址。
- 与 go2rtc 1.9.14 的 `subtype=hd/sd/auto/0-5` 语义一致。
